# שיבוץ מקומות באולם — גרסה מקומית V2

## הפעלה
1. התקינו Python 3.10 ומעלה.
2. פתחו CMD/PowerShell בתיקיית הפרויקט.
3. הריצו: `pip install -r requirements.txt`
4. הריצו: `python app.py`
5. פתחו בדפדפן: http://127.0.0.1:5000

כל הנתונים נשמרים מקומית בקובץ `data/state.json`.

## מה יש בגרסה
- מספר פרויקטים מקומיים.
- עורך אולם ידני: הוספה, מחיקה, גרירה ומיקום של שולחנות, קיבולת ודירוג.
- קבוצות עם סדר עדיפות בגרירה.
- אנשים, נעילות וייבוא CSV (שם, קבוצה).
- כללים אופציונליים: ביחד, בנפרד, חייב/אסור בשולחן; רך או קשיח.
- שיבוץ חכם שמתחשב בדירוג, עדיפות קבוצות, קיבולת, נעילות וכללים.
- עריכת מקומות ידנית בכל שולחן.
- זיהוי הפרות כללים.
- שמירת גרסאות ושחזור.
- גיבוי/שחזור JSON וייצוא CSV.
- מצב כהה.
